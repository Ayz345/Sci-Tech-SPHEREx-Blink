        Request log
          Keys: space play/pause · ←/→ epoch · 1–9 band · t previous band · b/d/s/c mode (c = false colour) · m measure · +/− zoom. Pixel scale is read from the manifest grid; SPHEREx native pixel is 6.15″. Methods

          Download measurements

          • This is a draft. Nothing is sent anywhere: the file is only downloaded to your computer.
          • Before submitting, test the file with the MPC's own checker: submit_psv_test. Submission form: submit_psv. Rules: reporting observations. Reading the rules and checking the file is your responsibility.
          • The MPC asks for at least three observations of an object per night and returns batches with single positions. A space telescope has no night, so the server counts 24-hour windows (UTC).
          • Station code 288 is SPHEREx. Submitting archival measurements under it may need a program code: contact the MPC first.
          • SPHEREx pixels are 6.15″ (the MPC advises 2–3″ for ground observers). The position uncertainty of every measurement is written in the file.
          • No magnitudes are included.
